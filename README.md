# CyberCore Client

Companion client mod for the CyberCore web app. Embeds a real Chromium browser (via [MCEF](https://github.com/CCBlueX/MCEF)) into Minecraft as a transparent HUD overlay, and bridges live player position and server events into the page.

This branch (`main`) only holds repository-level metadata (license, this file). The mod's source lives on version branches:

- [`26.1`](../../tree/26.1) — Minecraft 26.1.x
